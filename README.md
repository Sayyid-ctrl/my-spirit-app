# SEMANGAT BELAJAR — My Spirit App 📖✨

Aplikasi penyemangat dan pengelola target belajar santri / pelajar yang ringan, modern, responsif, dan dapat di-install di HP (Progressive Web App).

---

## 🌟 FITUR UTAMA
- 🌙 **Mode Gelap (Dark Mode)**: Hemat baterai & nyaman di mata.
- 📱 **PWA Ready**: Bisa di-install langsung di HP Android/iOS dari browser.
- 🎯 **Target Belajar Harian**: Catat & tandai target selesai dengan indikator progress visual.
- 💡 **Kumpulan Motivasi**: Berbagai motivasi islami/santri dengan pencarian & filter kategori.
- 📊 **Database Google Spreadsheet**: Tanpa backend Node.js, terhubung via Google Apps Script API.

---

## 🚀 CARA HOSTING KE GITHUB PAGES (ONLINE)

1. **Buat Repository Baru di GitHub**:
   - Buka [GitHub](https://github.com) dan buat repository baru bernama `semangat-belajar` (atau nama lain).
2. **Push File Proyek ke GitHub**:
   Jalankan perintah berikut pada terminal proyek:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - My Spirit App PWA"
   git branch -M main
   git remote add origin https://github.com/USERNAME_ANDA/semangat-belajar.git
   git push -u origin main
   ```
3. **Aktifkan GitHub Pages**:
   - Masuk ke Halaman Repository di GitHub.
   - Klik tab **Settings** > **Pages**.
   - Pada bagian **Build and deployment > Branch**, pilih `main` (atau `master`) dan folder `/(root)`.
   - Klik **Save**.
   - Tunggu 1–2 menit, link aplikasi Anda akan aktif di: `https://USERNAME_ANDA.github.io/semangat-belajar/`

---

## 📲 CARA INSTALL PWA DI HP
1. Buka link GitHub Pages Anda di browser HP (Chrome / Safari).
2. Tekan tombol **Menu (titik tiga di kanan atas / tombol Share di Safari)**.
3. Pilih **"Tambahkan ke Layar Utama" / "Add to Home Screen"** (atau **Install App**).
4. Aplikasi siap digunakan seperti aplikasi native dari Google Play Store!
